# Portfolio preview images

Drop your tour screenshots into this `assets/` folder using the **exact filenames**
below and they'll appear automatically as the portfolio tile previews on the
homepage ("Tours worth getting lost in"). No code changes needed.

`.jpg` is preferred (smaller); `.png` also works — the site tries `.jpg` first,
then `.png`, and falls back to the gradient placeholder if neither is present.

## Tips
- Landscape crops (roughly 16:9 or 3:2) look best; tiles crop to fill with
  `object-fit: cover`.
- A clean panorama frame (without the tour-viewer menu/logo chrome) reads best,
  but a straight screenshot is fine too.
- Keep files reasonably sized (ideally < 400 KB each) so the page stays fast.
